# Cap Bon Explorer

Portail web vitrine et interactif dédié à la découverte du patrimoine culturel, artisanal et naturel de la péninsule du Cap Bon (Tunisie).

## Informations sur le projet
* **Établissement :** ISET Nabeul
* **Module :** Développement Web / Mini-Projet Front-End
* **Réalisé par :** [Aymen jbili] — [Groupe 2]
* **Encadrant :** Mohamed Najeh Issaoui

## Structure du projet
* `index.html` : Page d'accueil, présentation et activités phares
* `activites.html` : Catalogue interactif des 8 activités avec recherche, filtre par catégorie et fenêtre modale
* `agenda.html` : Calendrier des 6 prochaines sorties programmées au Cap Bon
* `reservation.html` : Simulateur de réservation avec calcul tarifaire dynamique et remise automatique de 10 % dès 4 participants
* `contact.html` : Coordonnées, horaires d'accueil, carte statique, FAQ interactive et formulaire de contact simulé
* `css/style.css` : Charte graphique personnalisée (sable chaud, terre cuite, or et brun)
* `js/app.js`, `js/activites.js`, `js/reservation.js` : Données et logique JavaScript côté client

## Technologies utilisées
* HTML5 sémantique & CSS3 (Variables CSS, Flexbox, Media Queries)
* Bootstrap 5.3 (Grille responsive, Navbar, Cards, Modal, Accordion, Table)
* JavaScript Vanilla (DOM, événements, filtrage dynamique, validation de formulaire)

## Lancement
Ouvrir simplement le fichier `index.html` dans un navigateur web moderne (aucun serveur requis).
